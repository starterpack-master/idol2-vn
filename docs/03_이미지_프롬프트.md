# 이미지 발주 / 생성 프롬프트 시트

지금 게임은 **자동 생성 플레이스홀더**로 돌아갑니다. 아래 파일명으로 이미지를 넣기만 하면 코드 수정 없이 자동으로 교체됩니다.

```
public/assets/bg/{배경ID}.jpg        ← 360° 파노라마 (equirectangular, 2:1, 권장 4096×2048 / 최소 2048×1024)
public/assets/char/{캐릭터ID}_{표정}.png  ← 스탠딩 (투명 배경 PNG, 세로 1:2, 권장 1024×2048)
```

## 공통 규칙
- **파노라마 방향 규칙**: 이미지 **가로 정중앙 = 게임 시작 시 정면(yaw 0°)**, 오른쪽 1/4 지점 = 오른쪽(90°), 좌우 끝 = 뒤(180°). 대본의 `yaw=` 값이 이 기준이라, 배치가 중요한 오브젝트(칠판, 문)는 아래 표의 각도에 맞춰 주세요.
- 파노라마는 좌우 끝이 이음새 없이 이어져야 합니다(seamless). 생성 후 Photoshop ‘오프셋’ 필터로 이음새 확인.
- 360° 배경에는 **사람을 넣지 않습니다** (캐릭터는 스탠딩으로 올림).
- 스탠딩은 전신, 정면 약간 3/4, 발끝까지, 캐릭터 간 **머리 높이 기준 통일**.
- 등장인물이 고등학생이므로 노출·선정적 포즈 없이 교복/무대의상 모두 건전하게.

### 파노라마 공통 프롬프트 (앞에 붙이기)
```
360 degree equirectangular panorama, 2:1 aspect ratio, seamless horizontal wrap, camera at seated eye height, anime visual novel background art, detailed, soft lighting, no people,
```
(Blockade Labs Skybox AI를 쓰면 360°가 가장 쉽게 나옵니다. GPT/Midjourney는 `--ar 2:1` 후 이음새 보정 필요.)
