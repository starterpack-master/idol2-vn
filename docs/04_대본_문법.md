# 대본 문법 (.vn)

`src/script/` 안의 `.vn` 파일을 **파일명 순서대로** 이어 붙여 실행합니다. (`00_prologue.vn`, `01_ch1.vn` …) 라벨은 모든 파일에서 공유합니다.

## 대사
```
하린: 대사                 ← 캐릭터 이름(하린/서하린/harin) 또는 임의 이름(반 친구A)
하린[smile]: 대사          ← 표정 동시 변경
나: 주인공 대사            ← 주인공 이름으로 표시
그냥 한 줄은 나레이션
(괄호로 감싸면 속마음)
> 콜론이 들어가도 강제로 나레이션
{player}                   ← 주인공 이름으로 치환
```

## 연출
| 명령 | 설명 |
|---|---|
| `@bg classroom fade=600 yaw=0 pitch=0` | 360° 배경 교체 |
| `@view 180 0` | 카메라 즉시 이동 |
| `@look yaw=180 pitch=5 dur=1500 ease=inOut dir=right` | 카메라 회전 (dir: short/left/right, ease: inOut/out/in/linear) |
| `@lock` / `@unlock` | 플레이어 드래그 시점 조작 잠금/해제 |
| `@show harin smile yaw=180 dist=3 y=-1.3 h=7` | 캐릭터를 해당 방향에 배치 (dist 작을수록 가까움) |
| `@expr harin angry` / `@hide harin` / `@hideall` | 표정 / 퇴장 |
| `@wait 500` `@shake` `@flash` `@hidebox` | 대기, 흔들림, 번쩍, 대사창 숨김 |
| `@fade out 600` / `@fade in 600` | 암전 |
| `@chapter "제목" "부제"` | 챕터 카드 |
| `@autosave` | 자동 저장 지점 |
| `@chapter "제목" "부제" id=ch1` | `id`를 주면 챕터 선택 화면에 해금 (그 시점 호감도 저장) |
| `@bgm daily` / `@bgm stop` | BGM: `daily` `rooftop` `night` `tension` `live` (Web Audio 합성. `public/assets/bgm/{이름}.mp3`가 있으면 그걸 재생) |
| `@sfx door` | 효과음: `door` `vibe` `kakao` `pop` `heart` `down` `shock` `crowd` `step` `chime` |
| `@end "제목" "부제"` | 데모/엔딩 종료 |

## 변수와 분기
```
@add harin+3 scandal+2 flag:met_luna
@set route=harin known_luna=false
@if harin>=70 && scandal<40 -> ending_harin_good
@jump label   @call label   @return
#label
```
변수: `harin sera iseul luna trust scandal`(0~100 자동 클램프), `fans`, 그 외 자유.
`known_{id}=false`로 두면 이름이 `???`로 표시됩니다.

## 선택지
```
@choice timer=5000 default=1
- 텍스트 | harin+3 scandal+2 | -> label
- 조건부 선택지 | ? trust>=50 | trust+5 -> label
- 효과 없이 다음 줄로 진행
```
(빈 줄에서 블록 종료. `timer`는 시간제한 ms, 시간 초과 시 `default` 번째(0부터) 선택)

## 360° 탐색 (보는 곳 = 선택)
```
@explore "교실을 둘러보세요" need=1
- 60 12 "서하린" -> ex_harin
- 0 6 "수업에 집중한다" -> @next
```
각 핫스팟 라벨의 서브씬은 `@return`으로 끝내면 탐색으로 돌아옵니다. `@next`는 탐색 종료, `need=N`은 N곳을 본 뒤에야 `@next`가 나타남.

## 찾기
```
@find -90 26 "선반 맨 위를 찾아보세요" label="빛바랜 체키"
```
해당 방향을 0.7초 응시하거나 마커를 탭하면 진행.

## 폰 연출
```
@phone kakao "단톡방 이름"       ← kakao / dm / gallery / video / memo
= 시스템 메시지
< 서하린: 상대 메시지
> 내 메시지
@endphone

@phone gallery "지돌갤"

본문: 오픈카톡 캡처 있음 ㅋㅋ
* ㅇㅇ: 주작 아님?
@endphone

@phone video "YouTube"
캡션: 【4K 직캠】 ...
@endphone
```
