# 방과후 위험물 (放課後危険物) — 기획서

> 장르: 360° 파노라마 연애 시뮬레이션 / 지하아이돌 프로듀싱 ADV
> 플랫폼: 모바일 웹 (Three.js), 세로 화면 기준
> 목표 플레이타임: 1회차 약 3시간 (전 엔딩 수집 약 7~8시간)
> 한 줄 요약: **학교에선 찐따, 방과후엔 프로듀서.** 일진 여고생들을 홍대 지하돌로 데뷔시키다가 ‘프로듀서’로 남을지 ‘한 사람’을 택할지 선을 타는 이야기.

## 2. 작업 순서 (이 순서대로 진행)

미연시는 “대본부터 쓰면 망한다”가 정석입니다. 아래 순서로 **위에서 결정된 게 아래를 제약**하도록 짭니다.

1. **테마 고정** — 이 게임이 묻는 질문 하나: *“좋아하는 사람을 무대 위에 세우는 것과, 내 옆에 두는 것 중 무엇이 사랑인가?”* 모든 이벤트는 이 질문을 압박하는 방향으로만 넣는다.
2. **캐릭터의 욕망·결핍·비밀** — 캐릭터마다 ‘겉으로 원하는 것 / 진짜 필요한 것 / 숨기는 것’ 3개를 먼저 정한다. (아래 3장)
3. **시스템 변수 확정** — 호감도·신뢰·스캔들 수치가 무엇을 의미하는지 정해야 선택지를 쓸 수 있다. (아래 4장)
4. **엔딩부터 역산** — 엔딩 9개와 조건을 먼저 정하고, 그 조건을 만드는 선택지를 챕터에 심는다.
5. **3막 대구조 → 챕터 비트 → 씬 리스트** — 각 씬마다 “이 씬에서 무엇이 바뀌는가(관계·수치·정보)”가 없으면 삭제.
6. **에셋 리스트 추출** — 씬 리스트에서 배경(360°)·스탠딩·CG·UI(폰 화면) 목록을 뽑아 이미지 발주.
7. **대본 집필 (프롤로그부터)** — `script/*.vn` DSL로 바로 게임에 들어가게 쓴다.
8. **연출 태그 입히기** — 카메라 회전, 탐색, 폰 연출은 대본 초고 후 2차로.
9. **플레이 테스트 → 분량·페이싱 조정** — 챕터당 20분 초과 시 컷.

## 3. 캐릭터

### 한도윤 (주인공 / 플레이어, 이름 변경 가능) — 17세, 한울고 2학년 3반
- **겉**: 반에서 존재감 0. 점심시간엔 이어폰 끼고 일본 지하돌 직캠. 왕도계(청순·정통 아이돌) 파.
- **개연성 장치 (왜 하필 얘가 프로듀서?)**
  - 중2 여름, 도쿄 사는 삼촌 집에 한 달 머물며 지하돌 현장을 직접 다님 → 현장 문화(체키·특전회·믹스·운영 룰)를 몸으로 앎.
  - 홍대 라이브하우스 ‘클럽 언더스테이지’에서 일본 그룹 내한 공연 때 **통역·물판 알바**를 해서 사장과 안면이 있음 → 대관·운영 루트 확보.
  - 숨긴 취미: 보카로P ‘새벽3시P’로 DTM 작곡. 조회수는 적지만 곡은 좋음 → **오리지널 곡 문제 해결**.
- **결핍**: 무대 뒤에서만 빛나는 사람. “나 같은 게 저 애들 옆에 서도 되나?”
- **비밀**: 도쿄 시절 유일하게 편지를 썼던 아이돌이 있다. 그 아이돌이 지금 한국에 있다.

### 서하린 (메인 히로인) — 17세, 같은 반
- **겉**: 반 최상위 인싸, 약간 일진 기질. 누구와도 잘 지내지만 선은 확실. 도윤을 ‘조련’하는 타입.
- **계기**: 유튜브 알고리즘으로 일본 그룹 ‘큐티 애비뉴(큐애비)’ 무대를 보고 빠짐. 동시에 “체키 한 장 2천 엔? 한국에서 만 원 받아도 개꿀” 이라는 계산.
- **진짜 동기(비밀)**: 엄마 혼자 하는 망원동 분식집의 밀린 월세. 돈 얘기는 절대 안 함.
- **성장**: 돈 → “나를 보러 와준 일곱 명” → 무대 자체. 중반 이후 체키 매출보다 팬 편지를 더 소중히 여긴다.
- **무대명**: 하린 / 담당색 빨강 / 포지션 센터·댄스

### 백세라 (서브1) — 17세, 옆 반, 하린의 짱친
- **겉**: 털털한 일진 갭모에. “하린이 하면 나도. 돈 된다며?”
- **재능**: 가치코이(진심 연애 착각) 먹이는 천재. 눈 맞추고 이름 불러주고 “너만 보여” 레스를 자연스럽게 함.
- **도윤 공략 방식**: “가치코이 연습이야, 연습.” 을 핑계로 도윤에게 계속 레스 연습. 어디까지가 연습인지 본인도 헷갈리기 시작한다.
- **비밀/결핍**: 누구에게나 ‘가짜로’ 사랑받는 법은 아는데 진짜로 사랑받아본 적이 없다고 믿음. 그래서 DM으로 명품을 주겠다는 팬에게 흔들린다(Ch5).
- **무대명**: 세라 / 파랑 / 비주얼·팬서비스

### 윤이슬 (서브2) — 17세, 같은 반 창가 자리
- **겉**: 말수 적고 앞머리로 눈을 가리는 조용한 아이. 사실 도윤만큼 서브컬처 덕후.

- **재능/약점**: 노래는 셋 중 압도적. 무대공포증.

### 루나 (강루나, 서브3·라이벌) — 19세, 라이벌 그룹 ‘NOCTURNE(녹턴)’ 센터

## 4. 게임 시스템

### 변수
| 변수 | 범위 | 의미 |
|---|---|---|
| `harin` `sera` `iseul` `luna` | 0~100 | 개인 호감도 (**연애 감정**) |
| `trust` | 0~100 | 그룹 전체의 **프로듀서 신뢰도** (프로로서의 판단력) |
| `scandal` | 0~100 | 스캔들 위험도. 연애적 선택·사건 대처 실패로 오름. 70 이상에서 배드 분기 개방 |
| `fans` | 인원 | 동원 수. 사건 대처·곡 선택으로 증감 |
| 플래그 | bool | `met_luna_dm`, `rule_made`, `reply_statement` 등 |

### 핵심 설계: “선 타는 선택지”
대부분의 로맨스 선택지는 **호감도↑ = 스캔들↑ 또는 신뢰↓** 로 설계합니다.
예) 연습 끝나고 하린을 집까지 데려다준다 → `harin +5, scandal +4`
→ 플레이어는 좋아하는 캐릭터에게 다가갈수록 **그룹을 위험하게 만든다**는 걸 체감. 엔딩 선택의 무게가 여기서 나옵니다.

### 360° 파노라마 연출 3종 (이 게임만의 차별점)
1. **강제 회전(시선 연출)** — `@look` : “뒤통수가 따가운데?” → 카메라가 스윽 돌아가 어깨 너머의 하린 발견.
2. **자유 탐색(관찰형 선택지)** — `@explore` : 화면을 돌려 **어디를 보느냐**가 곧 선택. 누구를 보았는지에 따라 호감도·정보가 달라짐. (예: 5교시에 하린/이슬/세라 중 누구를 몰래 볼까)
3. **찾기(긴장 연출)** — `@find` : 공연 전 사라진 이슬 찾기, 밤 골목에서 뒤따라오는 발소리의 주인 찾기.
4. **시간제한 선택지** — 스킨십 사건 등 즉시 판단이 필요한 순간 `timer=` 사용.

### 폰 UI 연출
직캠 영상, 카톡 단톡, 트위터 DM, 지돌갤 게시글·댓글을 **폰 화면 오버레이**로 보여줌. 고자극 이벤트(루머·DM쯔)는 거의 전부 폰으로 터진다.
