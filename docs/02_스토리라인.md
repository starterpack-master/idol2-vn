## 프롤로그 — 뒤통수가 따가운 점심시간 ✅ 집필 완료 (`src/script/prologue.vn`)
- **점심시간 교실**: 도윤, 이어폰 끼고 하이네코 직캠. (폰 오버레이, 화면 고정)
- “……어라. 뒤통수가 좀 따가운데?” → **카메라 180° 회전** → 어깨 너머 초근접 하린.
- 하린: “이거 큐애비랑 같은 쪽이지? 너 이런 거 잘 알아?” 선택지 3개(당황/설명충/역질문).
- 세라가 문에서 하린을 부름. 하린: “방과후. 옥상. 안 오면 죽음.”
- **5교시 자유 탐색**: 하린(몰래 큐애비 영상 보는 중) / 이슬(눈 마주치자 황급히 피함) / 세라(윙크) — 누구를 보느냐에 따라 호감도.
- **옥상 노을**: “나 지하아이돌 할 거야. 네가 프로듀싱 해.” 도윤이 현실적 조건(멤버 3인, 곡, 공연장, 돈)을 늘어놓다 오타쿠 설명 모드 폭주 → 하린 감탄. 하린의 폰에 뜬 ‘엄마: 이번 달 월세…’ 알림(돈 동기 복선).
- 거절하면 하린의 협박(“수학여행 때 너 오타게 연습하던 영상 나한테 있다?”)
- 뒤에서 옥상 문 끼익 → **카메라 회전** → 이슬: “저, 저도…… 할래요.”
- **밤, 도윤 방**: 단톡방 ‘방과후 위험물(가칭)’ 초대. 그리고 모르는 계정 DM: *“오랜만이야. 내 첫 번째 팬♡ — @luna_nocturne”*

## Ch1 — 위험물 결성 ✅ 집필 완료 (`src/script/01_ch1.vn`, 약 8,000자)
- 다음 날 점심, 옥상 첫 회의. 이슬 합류 이유를 캐묻는 하린(질투 씨앗). 세라의 동기: “돈 된다며?”
- 도윤의 사업계획서(진지함) → 체키 단가·대관비·연습실비 계산. **하린이 누구보다 숫자를 열심히 들음** (복선).
- 곡 문제: 커버곡은 저작권·임팩트 문제. 이슬이 “새벽3시P 곡 쓰면 되잖아요” → 도윤 정체 발각, 이슬이 오래된 팬임이 드러남. `iseul +`
- 홍대 클럽 언더스테이지 방문 (360° 라이브하우스 첫 등장, 탐색으로 무대·물판·객석 구조 학습). 곽 사장: “미성년자 셋? 부모 동의서 가져와. 계약은 내 이름으로.”
- 그룹명 회의(선택지 3개 → 전부 하린이 거부하고 ‘방과후 위험물’로 확정하는 개그).
- 선택: 연습실비를 누가 내나 (도윤 알바비 선결제 `trust +, harin +` / N빵 / 하린에게 맡김)

## Ch2 — 연습과 가치코이 연습
- 합정 B2 연습실 몽타주. 하린=춤 천재, 세라=표정·레스 천재, 이슬=노래 천재지만 관객 앞에서 얼어붙음.
- **세라의 가치코이 연습 이벤트**: “프로듀서면 연습 상대 해줘야지.” 눈 맞춤·이름 부르기·손하트 레스. 선 타는 선택지 (끝까지 받아준다 `sera ++ scandal +` / 프로듀서답게 피드백 `trust +`).
- 이슬과 밤 통화: 무대공포증 고백. 도윤이 무대용 ‘시선 둘 곳’ 조언 → Ch3 복선.
- 곽 사장 소개로 녹턴 공연 견학 → **루나 첫 대면**. 객석 전체가 루나에게 먹히는 걸 360°로 체감(둘러보면 모든 관객이 넋이 나가 있음). 공연 후 루나: “편지 아직 갖고 있어. 한국어로 쓴 거.” 하린·세라·이슬 셋 다 굳음.

## Ch3 — 관객 일곱 명 (데뷔)
- 데뷔 당일 대기실. **이슬 실종** → `@find`로 백스테이지 창고에서 찾기. 도윤의 말 선택(“나만 봐” `iseul ++ scandal +` / “팬을 봐” `trust +`).
- 무대: 무대 위 시점 360°. 관객 7명, 그중 철벽형님의 완벽한 믹스.
- 첫 체키회: 매출 7만 원. 하린 실망 → 한 팬의 손편지(“오늘부터 하린이 최애”) 받고 편의점 앞에서 몰래 울다 도윤에게 들킴. `harin ++`
- 엔딩 훅: 지돌갤에 첫 후기 글. 댓글에 누군가 “센터 표정 썩었던데 ㅋ”.

## Ch4 — 손을 놓지 않는 남자
- 관객 30명으로 증가, 체키회 줄이 생김. **핑크덕**: 악수 시간 초과, 체키 포즈 때 세라 어깨에 손.
- **시간제한 선택지(5초)**: 즉시 끼어든다 `trust ++ sera +` / 스태프(곽 사장) 부른다 `trust +` / 참는다 `trust -- sera --`
- 사후 처리: 체키 규정 공지(터치 금지·포즈 규정·출금 기준) 작성 선택지. `flag rule_made`
- **리본(멘헤라 팬)**: 매 공연 이슬에게 긴 편지·“이슬쨩 없으면 못 살아” DM. 이슬은 자신을 보는 것 같아 거절 못 함. 도윤의 대처(경계 세우기 + 도움 받을 곳 안내 / 무시 / 이슬에게 맡김)에 따라 리본이 Ch8 페스에서 조력자 또는 방해자.

## Ch5 — DM쯔와 쯔나가리
- **세라 DM쯔**: 부자 팬 ‘G바겐오빠’가 가방 사진과 함께 “따로 만나면 이거 줄게”. 쉬는 시간, 이번엔 **도윤이 세라의 어깨 너머로 폰을 보게 됨** (프롤로그의 반전 연출).
- 대화 선택: 혼낸다 `sera -- trust +` / 왜 흔들렸는지 묻는다 `sera ++` / 모른 척 `scandal ++`
- 세라의 고백: “가짜로 사랑받는 건 잘하는데, 진짜는 모르겠어.”
- 같은 주, **지돌갤 루머**: “위험물 하린 쯔나가리 한다더라 (오픈카톡 캡처)”. 폰으로 게시글·댓글 폭주 연출.
- **공식 입장문 선택**: 강경 부인+법적 대응 예고 `scandal -- fans -` / 침묵 `scandal +` / 멤버가 직접 방송 해명 `trust + harin +`
- 캡처 원본 IP가 이상하다는 철벽형님의 제보 (녹턴 복선).

## Ch6 — 사진 한 장
- 연습 끝 밤 편의점. 하린이 처음으로 월세 얘기를 털어놓음. **선 타는 선택지**: 머리 쓰다듬기 `harin +++ scandal ++` / 캔커피 건네기 `harin + ` / 조용히 옆에 있기 `harin ++`
- 다음 날 지돌갤: 두 사람 사진 + “위험물 센터 남친 있음 ㅋㅋ 같은 학교 찐따임”.
- **학교 발각**: 반 전체가 수군거림 — `@explore`로 교실을 둘러보면 누가 무슨 말을 하는지 들림(악의/호기심/옹호). 이슬·세라의 반응.
- 담임 호출. 하린 엄마 등장, 아이돌 활동 반대.
- 분기: `trust ≥ 50`이면 하린이 반 친구들 앞에서 “얘 우리 프로듀서거든? 건드리지 마.” / 아니면 하린이 도윤을 피하기 시작.

## Ch7 — 밤의 발소리
- ‘선물남’ 정우의 DM이 점점 이상해짐 (폰 연출: 답장 안 하면 메시지 10개 연속).
- 하린 귀갓길을 도윤이 몰래 지켜주던 밤 골목, **발소리** → `@find`로 뒤를 돌아 그림자 찾기 (공포 연출). 신고, 곽 사장·철벽형님 합류, 정우 검거. 사진 찍은 것도 정우였음.
- 그러나 루머를 퍼뜨린 건 따로 있다: 루나가 도윤을 불러내 녹턴 이적 제안. “너 곡이면 우리가 서지페 1위야. 그리고…… 넌 원래 내 팬이었잖아?”
- 루나가 증거(진상철의 부계정 캡처)를 건넴. 받는 대가로 “페스 끝나고 대답해줘”.
- 선택: 제안을 보류 `luna + flag luna_pending` / 즉시 거절 `trust +` (루나 루트는 보류해야만 개방)

## Ch8 — 서지페 (서울 지하돌 페스)
- 입장문과 증거 공개로 여론 반전(Ch5 선택에 따라 효과 차등). 리본의 도움 여부.
- 페스 당일, 녹턴 바로 뒤 순서. 공연 직전 **루트 확정 탐색**: 공연장 옥상에서 360° — 문 쪽 하린 / 난간 쪽 세라 / 계단 쪽 이슬 / 건너편 건물 옥상 루나(보류 시). **누구에게 걸어가느냐 = 루트 확정.** 아무에게도 가지 않고 무대로 내려가기 = 프로듀서 루트.
- 무대: 신곡(도윤 작곡) 무대 360°. 객석 규모는 `fans` 수치 반영.

## 엔딩 — 방과후가 끝나면
최종 선택지: **“프로듀서로 남는다” / “그녀의 손을 잡는다”**

| # | 엔딩 | 조건 |
|---|---|---|
| 1 | **TRUE: 방과후는 계속된다** (프로듀서) | 프로듀서 선택, `trust ≥ 70`, `scandal < 40` |
| 2 | NORMAL: 평범한 오타쿠로 | 프로듀서 선택, 조건 미달 — 그룹은 계속되지만 도윤은 떠남 |
| 3 | 하린 GOOD: 졸업식 날의 고백 | 하린 루트, `harin ≥ 70`, `trust ≥ 50` — “졸업하는 날까진 아이돌. 그다음은 네 거.” |
| 4 | 하린 BAD: 둘만 남은 무대 | 하린 루트, `scandal ≥ 70` — 그룹 해체, 텅 빈 언더스테이지 |
| 5 | 세라 GOOD: 연습 끝 | 세라 루트, `sera ≥ 70` — “이제 연습 아니야.” |
| 6 | 이슬 GOOD: 새벽3시의 노래 | 이슬 루트, `iseul ≥ 70` — 이슬이 도윤의 곡으로 솔로 데뷔, 가사는 도윤에게 쓴 것 |
| 7 | 루나 END: 밤의 프로듀서 | 루나 루트 — 녹턴 탈퇴한 루나와 새 출발. 위험물은 도윤 없이 남음(씁쓸) |
| 8 | BAD: 해체 공지 | 모든 루트 공통, `scandal ≥ 90` |
| 9 | HAREM(히든): 위험물은 전원 위험하다 | 4인 전원 `≥ 60` & `trust ≥ 70` — 개그 엔딩 |
